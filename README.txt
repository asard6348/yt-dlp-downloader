--- Yt-dlp Downloader ---


Use these scripts for easy access to yt-dlp and to download most Youtube videos the user-friendly way.

For basic use is recommended the shell version, for more advanced the GUI with adjustable JSON config file (gui-config).

Yt-dlp program is required to be installed, either its directory added to PATH environment variable or just the executable file put inside the working directory of these scripts, of course.

Install yt-dlp from this website: https://github.com/yt-dlp/yt-dlp

--- Yt-dlp Downloader ---


Use these scripts for easy access to yt-dlp and to download most Youtube videos the user-friendly way.

For basic use is recommended the shell version, for more advanced the GUI with adjustable JSON config file (gui-config).


--- Requirements ---


Yt-dlp library or program is required to be installed, either its directory added to PATH environment variable or just the executable file put inside the working directory of these scripts.
-> Install here: 
https://github.com/yt-dlp/yt-dlp
-> or using "pip install yt-dlp" in terminal/TTY.

FFmpeg program is required to be installed for post-processing of the downloaded file format.
-> Install here:
https://www.ffmpeg.org/download.html
